# Car inspection stats

Shiny app for exploring Finnish [car inspection data](https://trafi2.stat.fi/PXWeb/pxweb/en/TraFi/TraFi__Katsastuksen_vikatilastot/020_kats_tau_102.px/), which runs entirely in the browser via [webR](https://docs.r-wasm.org/webr/latest/)/[shinylive](https://posit-dev.github.io/r-shinylive/). 

A live version is deployed at [vansinne.se/besiktning](https://vansinne.se/besiktning/).
